## درباره برنامه

NEXORA DAILYKIT یک برنامه دسکتاپ محلی برای ویندوز است که تقویم، برنامه‌ریزی روزانه، وظایف، یادداشت‌ها، یادآورها و اطلاعات تاریخ را در یک محیط جمع‌وجور قرار می‌دهد.

سه تقویم پشتیبانی می‌شوند: میلادی، شمسی/جلالی و اسلامی.

رابط برنامه در حال حاضر فقط **انگلیسی و فارسی** است؛ زبان‌های دیگر README فقط زبان مستندات هستند.

اطلاعات تقویم، Task، Journal، Reminder و Backup به‌صورت محلی ذخیره می‌شوند و برای استفاده عادی به حساب آنلاین یا فضای ابری نیاز نیست.

## امکانات

- تقویم میلادی، شمسی/جلالی و اسلامی
- اطلاعات روز انتخاب‌شده
- Task با توضیح و زمان اختیاری
- Journal بر اساس تاریخ
- اعلان یادآور ویندوز
- صدای سفارشی، حجم صدا، Snooze و Dismiss
- ویجت دسکتاپ
- تنظیم شفافیت ویجت
- System Tray
- تم روشن، تیره و سیستم
- رنگ اصلی و رنگ مستقل تقویم، Task، Journal و Reminder
- شخصی‌سازی تقویم و ویجت
- Backup خودکار و دستی
- Restore همراه با پشتیبان ایمنی
- رابط انگلیسی/فارسی با LTR/RTL
- ذخیره‌سازی محلی
- About Us با لینک‌های NEXORA و اطلاعات حمایت مالی

## نیازمندی سیستم

# 📖 راهنمای کامل کار با برنامه

## 1. اولین اجرا

تنظیمات اولیه شامل رابط انگلیسی، تقویم میلادی، ویجت در محدوده پایین سمت چپ بالای Taskbar، شفافیت پیش‌فرض و ذخیره‌سازی محلی است.

## 2. رابط اصلی

### Calendar
تقویم انتخاب‌شده را نمایش می‌دهد و امکان جابه‌جایی بین تاریخ‌ها و ماه‌ها را فراهم می‌کند.

### Settings
شامل تنظیمات Appearance، Calendar، Widget، Reminders، Backup، Language و About است.

### About Us
اطلاعات NEXORA، لینک‌های پروژه، حمایت مالی و امکان کپی Wallet را دارد.

نام برنامه همیشه **NEXORA DAILYKIT** است.

> **جای تصویر:** اسکرین‌شات رابط اصلی.

## 3. تقویم

می‌توانید ماه‌ها را جابه‌جا کنید، تاریخ انتخاب کنید، به Today برگردید، تقویم اصلی را تغییر دهید، تقویم‌های دیگر را نمایش دهید و اطلاعات روز را باز کنید.

تاریخ انتخاب‌شده برجسته اصلی را دارد. امروز نیز مشخص می‌ماند و با انتخاب تاریخ دیگر، برجستگی امروز ملایم‌تر می‌شود.

> **جای تصویر:** اسکرین‌شات تقویم.

## 4. سیستم‌های تقویمی

### Gregorian
تقویم استاندارد بین‌المللی.

### Persian / Jalali
تقویم خورشیدی هجری ایرانی.

### Islamic
تقویم هجری اسلامی.

تاریخ‌های اسلامی از داده‌های مبتنی بر Umm al-Qura استفاده می‌کنند و ممکن است با تقویم‌های مبتنی بر رؤیت محلی ماه حدود یک روز اختلاف داشته باشند. جلالی از محاسبه نجومی Solar Hijri پشتیبانی‌شده استفاده می‌کند.

## 5. تنظیمات نمایش تقویم

مسیر: **Settings → Calendar**

شامل تقویم اصلی، تقویم دوم و سوم، قالب تاریخ، قالب اعداد و اولین روز هفته است.

اولین روز هفته می‌تواند خودکار، شنبه، یکشنبه یا دوشنبه باشد.

در رابط فارسی، اعداد تاریخ به‌صورت Western/English باقی می‌مانند.

## 7. وظایف

هر Task می‌تواند عنوان، توضیح اختیاری، زمان اختیاری و وضعیت انجام داشته باشد.

ساخت، ویرایش، تکمیل، بازکردن مجدد و حذف امکان‌پذیر است.

برای ساخت: تاریخ را انتخاب کنید → Daily Information → **New Task** → عنوان → توضیح/زمان اختیاری → ذخیره.

Task دارای زمان می‌تواند توسط Reminder Engine یادآوری شود.

## 8. Journal

Journal برای یادداشت روزانه است، نه کار قابل انجام. ذخیره خودکار و دستی دارد.

برای یادداشت روزانه، ایده، ثبت شخصی، یادداشت جلسه و موارد مشابه استفاده کنید.

## 9. یادآورها

Task می‌تواند زمان Reminder داشته باشد. هنگام رسیدن زمان، برنامه می‌تواند اعلان Windows، صدای تنظیم‌شده، Snooze یا Dismiss را ارائه کند.

Reminderهای زمان‌بندی‌شده هنگام اجرای برنامه دوباره بارگذاری می‌شوند.

تنظیمات و مجوزهای اعلان Windows نیز مؤثر هستند.

> **جای تصویر:** Reminder Notification.

## 10. تنظیمات Reminder

مسیر: **Settings → Reminders**

گزینه‌ها: صدای یادآور، صدای پیش‌فرض/سفارشی، Test، Stop Sound، Volume و Default Snooze.

با **Test** صدا را امتحان و با **Stop Sound** متوقف کنید.

> **جای تصویر:** Reminder Settings.

## 11. ویجت دسکتاپ

ویجت به‌صورت پیش‌فرض پایین سمت چپ و بالای Taskbar است.

می‌توان آن را جابه‌جا، Resize، نمایش/مخفی، برای Start with Windows تنظیم، به Tray منتقل و Reset Position کرد.

Desktop Layer **پشت پنجره‌های عادی** است؛ Always-on-top نیست و Focus را نمی‌گیرد. بازیابی موقعیت چندمانیتوره نیز پشتیبانی می‌شود.

> **جای تصویر:** Desktop Widget.

## 12. شفافیت ویجت

از **20% تا 100%** قابل تنظیم است.

هنگام تعامل با تقویم، ویجت موقتاً 100% می‌شود و بعد به مقدار تنظیم‌شده برمی‌گردد. مقدار ذخیره‌شده تغییر نمی‌کند.

> **جای تصویر:** Opacity Settings.

## 13. System Tray

بستن ویجت معمولاً برنامه را متوقف نمی‌کند. برنامه می‌تواند در System Tray فعال بماند.

منوی Tray برای Show، Hide و **Exit** است. فقط Exit برنامه را کاملاً می‌بندد.

> **جای تصویر:** System Tray.

## 14. Settings

از نوار بالایی وارد **Settings** شوید.

بخش‌ها: Appearance، Calendar، Widget، Reminders، Backup، Language و About.

> **جای تصویر:** Settings Overview.

## 15. Appearance

مسیر: **Settings → Appearance**

شامل Theme، Accent Color، رنگ Calendar/Task/Journal/Reminder، Background، رنگ متن، Font Size/Scale و Density است.

تم روشن، تیره و سیستم پشتیبانی می‌شود. Preview برای مشاهده تغییرات و Reset برای بازگردانی ظاهر استفاده می‌شود.

> **جای تصویر:** Appearance Settings.

## 16. Language

مسیر: **Settings → Language**

زبان‌های رابط:

- English
- Persian

زبان پیش‌فرض نصب اول English است. فارسی در بخش‌های لازم RTL است و URL و Wallet به‌صورت LTR خوانا باقی می‌مانند.

هشت زبان README به معنی پشتیبانی رابط برنامه از هشت زبان نیست.

> **جای تصویر:** Language Settings.

## 17. Backup & Restore

مسیر: **Settings → Backup**

پشتیبان خودکار، زمان‌بندی، مسیر، Retention، Backup دستی و Restore قابل تنظیم است.

زمان‌بندی‌ها: Daily، Weekly و On exit.

مسیر پیش‌فرض:

`Documents/Nexora DailyKit/Backups`

**Open Folder** مسیر فعلی تنظیم‌شده را باز می‌کند. **Backup Now** پشتیبان فوری می‌سازد.

> **جای تصویر:** Backup Settings.

## 18. Restore

قبل از Restore از داده فعلی پشتیبان ایمنی ساخته می‌شود.

1. Settings → Backup.
2. مسیر را بررسی کنید.
3. Restore را انتخاب کنید.
4. Backup را انتخاب کنید.
5. تأیید کنید.
6. منتظر پایان بمانید.
7. در صورت درخواست برنامه را دوباره باز/Refresh کنید.

در زمان Restore برنامه را متوقف نکنید.

## 20. Data Storage & Privacy

NEXORA DAILYKIT یک برنامه دسکتاپ محلی است.

اطلاعات تقویم، Task، Journal، Reminder، Settings و Backup روی کامپیوتر ذخیره می‌شوند.

برای استفاده عادی حساب NEXORA، حساب ابری، اشتراک یا Online Sync لازم نیست.

اینترنت فقط هنگام باز کردن عمدی لینک خارجی مانند Telegram، GitHub یا Donate استفاده می‌شود.

> **مهم:** امنیت داده محلی به امنیت حساب Windows و پوشه‌های ذخیره‌سازی نیز وابسته است.

## 21. رفع اشکال

**ویجت ناپدید شد:** System Tray را بررسی و Show کنید.

**موقعیت اشتباه:** Settings → Widget → Reset Position.

**Reminder نیامد:** زمان Task، ذخیره Task، وضعیت برنامه/Tray، اعلان‌های Windows و تنظیمات Reminder را بررسی کنید.

**صدا نیست:** صدای Windows، صدای Reminder و Sound انتخاب‌شده را بررسی و Test Sound را اجرا کنید.

**پوشه Backup اشتباه:** Settings → Backup و سپس Open Folder.

**نمایش فارسی:** Language را روی Persian بگذارید.

**اختلاف یک‌روزه تاریخ اسلامی:** تفاوت روش‌های محاسبه، به‌خصوص Umm al-Qura و رؤیت محلی، می‌تواند باعث اختلاف شود.
