## О приложении

NEXORA DAILYKIT — локальное Windows-приложение для календаря, планирования дня, задач, Journal, напоминаний и информации о датах. Поддерживаются Gregorian, Persian/Jalali и Islamic. Интерфейс приложения сейчас доступен только на **English и Persian**; остальные языки README предназначены только для документации.

---

## Возможности

- Gregorian, Persian/Jalali и Islamic
- Информация выбранного дня
- Задачи с описанием и временем
- Journal по датам
- Уведомления Windows
- Пользовательские звуки, громкость, Snooze и Dismiss
- Desktop Layer виджет и прозрачность
- System Tray
- Светлая, тёмная и системная темы
- Цвета Calendar/Task/Journal/Reminder
- Настройка календаря и виджета
- Автоматическое и ручное резервное копирование
- Restore с защитной копией
- English/Persian и LTR/RTL
- Локальное хранение данных
- About Us и ссылки NEXORA

## Системные требования

- Windows 10 или Windows 11
- Учётная запись Windows с правами установки и запуска
- Интернет не нужен для обычной работы календаря, задач, Journal, напоминаний и резервных копий

## Установка

1. Скачайте последний Windows Installer из Releases.
2. Запустите установщик.
3. Завершите установку.
4. Запустите **NEXORA DAILYKIT**.
5. При первом запуске используются **English** и **Gregorian**.
6. Откройте **Settings** для настройки приложения.

# 📖 Полное руководство пользователя

## 1. Первый запуск

По умолчанию используются английский интерфейс, григорианский календарь, виджет в нижней левой части экрана над панелью задач, стандартная прозрачность и локальное хранение.

<img width="358" height="531" alt="image" src="https://github.com/user-attachments/assets/d09fc578-5695-4d78-adb6-6fa3c091c587" />

## 2. Главный интерфейс

**Calendar** показывает календарь и позволяет переходить между датами и месяцами. **Settings** управляет внешним видом, календарём, виджетом, напоминаниями, резервными копиями и языком. **About Us** содержит информацию NEXORA, ссылки проекта, поддержку и копирование кошелька. Название всегда **NEXORA DAILYKIT**.


## 3. Календарь

Можно менять месяцы, выбирать дату, использовать Today, менять основной календарь, показывать дополнительные календари и открывать информацию выбранного дня. Выбранная дата получает основное выделение, а сегодня остаётся видимым и становится светлее при выборе другой даты.

<img width="350" height="422" alt="image" src="https://github.com/user-attachments/assets/58da5456-638c-4dc3-9bd1-0f1b69652f46" />

## 4. Календарные системы

**Gregorian:** международный стандарт. **Persian / Jalali:** персидский солнечный календарь. **Islamic:** исламский Hijri. Islamic использует Umm al-Qura и может отличаться примерно на один день от календарей местного наблюдения луны. Jalali использует поддерживаемый астрономический расчёт Solar Hijri.


## 5. Настройки отображения календаря

**Settings → Calendar** позволяет выбрать основной, второй и третий календарь, формат даты, формат чисел и первый день недели. Первый день: автоматически, суббота, воскресенье или понедельник. В персидском интерфейсе цифры дат остаются западными/английскими.

<img width="579" height="500" alt="image" src="https://github.com/user-attachments/assets/f3fbfb5e-f818-49f2-bace-e69ff5203855" />

## 6. Информация дня

Выбор даты открывает Daily Information. **Tasks** содержит выполняемые элементы, а **Journal** — свободные заметки выбранного дня.

<img width="410" height="552" alt="image" src="https://github.com/user-attachments/assets/595f7b5e-7a52-410e-8440-80f0b38c989e" />

## 7. Задачи

Задача может иметь название, необязательное описание, необязательное время и статус выполнения. Доступны создание, редактирование, завершение, повторное открытие и удаление. Выберите дату → Daily Information → **New Task** → введите данные → сохраните. Время задачи может использоваться для напоминания.

<img width="1048" height="536" alt="image" src="https://github.com/user-attachments/assets/7e85eada-f3b1-4a39-b496-bced2bae5c58" />

## 8. Journal

Journal предназначен для заметок по дате. Поддерживаются автоматическое и ручное сохранение. Используйте его для дневных заметок, идей, личных записей и заметок встреч.

<img width="362" height="532" alt="image" src="https://github.com/user-attachments/assets/da8de7d1-f96e-402f-926f-3cbd42f0287f" />

## 9. Напоминания

Для задачи можно установить время напоминания. При наступлении времени доступны уведомление Windows, звук, Snooze и Dismiss. Запланированные напоминания снова загружаются при запуске приложения. Настройки уведомлений Windows также влияют на показ.

<img width="333" height="112" alt="image" src="https://github.com/user-attachments/assets/025a3d25-5f97-4602-98f2-bd4cefa3203d" />

## 10. Настройки напоминаний

**Settings → Reminders**: звук, стандартный/пользовательский звук, Test, Stop Sound, громкость и стандартный Snooze.

<img width="500" height="386" alt="image" src="https://github.com/user-attachments/assets/898cbfe4-2e40-4f2e-9e3c-a20a04c0ff98" />

## 11. Настольный виджет

По умолчанию виджет расположен внизу слева над панелью задач. Его можно перемещать, менять размер, показывать/скрывать, запускать с Windows, закрывать в Tray и сбрасывать позицию. Desktop Layer находится **позади обычных окон**, не является Always-on-top и не забирает фокус. Поддерживается восстановление позиции на нескольких мониторах.

<img width="338" height="468" alt="image" src="https://github.com/user-attachments/assets/ea0d0977-9c5a-4eb3-8d65-8c6dbb2fab62" />

## 12. Прозрачность виджета

Можно выбрать 20–100 %. Во время работы с календарём виджет временно становится полностью видимым, после чего возвращается к сохранённой прозрачности. Сохранённое значение не изменяется.

<img width="465" height="396" alt="image" src="https://github.com/user-attachments/assets/45d07eaf-8b05-4868-80b0-8fcbb0977427" />

## 13. Системный трей

Закрытие виджета обычно не завершает приложение. В Tray доступны показ, скрытие и **Exit**. Только Exit полностью завершает приложение.


## 14. Настройки

Через **Settings** доступны Appearance, Calendar, Widget, Reminders, Backup, Language и About.

## 15. Внешний вид

**Settings → Appearance** позволяет настроить тему, акцентный цвет, цвета Calendar/Task/Journal/Reminder, фон, текст, размер шрифта и плотность. Поддерживаются светлая, тёмная и системная темы, Preview и Reset.

## 16. Язык

**Settings → Language**. Сейчас доступны English и Persian. При первом запуске используется English. Персидский интерфейс использует RTL там, где необходимо, а URL и кошелёк остаются LTR. Восемь языков README не означают восемь языков интерфейса приложения.

<img width="387" height="287" alt="image" src="https://github.com/user-attachments/assets/ede484b5-2075-43b8-81ff-2d01faee0105" />

## 17. Резервное копирование и восстановление

**Settings → Backup** позволяет настроить автоматическое резервное копирование, частоту, место, хранение, ручной Backup и Restore. Частота: Daily, Weekly, On exit. По умолчанию: `Documents/Nexora DailyKit/Backups`. Open Folder открывает текущий путь, Backup Now создаёт копию сразу.

<img width="579" height="454" alt="image" src="https://github.com/user-attachments/assets/4e30b4db-7bd9-4ec1-9b1b-5173f774b9fd" />

## 18. Восстановление

Перед Restore создаётся защитная копия текущих данных. Откройте Settings → Backup → Restore → выберите копию → подтвердите → дождитесь завершения. При необходимости перезапустите/обновите приложение. Не прерывайте восстановление.

## 20. Хранение данных и конфиденциальность

Календарь, задачи, Journal, напоминания, настройки и резервные копии хранятся локально. Для обычной работы не нужны аккаунт NEXORA, облако, подписка или онлайн-синхронизация. Интернет используется только при намеренном открытии внешних ссылок. Безопасность локальных данных также зависит от Windows-аккаунта и папок хранения.


## 21. Устранение неполадок

Виджет исчез: проверьте System Tray. Неверная позиция: Settings → Widget → Reset Position. Нет напоминания: проверьте время задачи, сохранение, App/Tray, уведомления Windows и Reminder. Нет звука: проверьте громкость Windows/Reminder и выбранный звук, затем Test Sound. Неверный Backup-путь: Settings → Backup → Open Folder. Персидский: Language → Persian. Разница Islamic в один день может быть вызвана методикой расчёта.


## 22. Техническая заметка о календарях

Jalali использует поддерживаемый астрономический расчёт Solar Hijri. Islamic использует данные Umm al-Qura и не является календарём местного наблюдения луны. Поэтому некоторые исламские даты могут отличаться примерно на один день.
